# Custom Hideout Recipes

# Installation
Install [Hideout Recipe Framework](https://forge.sp-tarkov.com/mod/2520/hideout-recipe-framework)
Run the server once.

# Updating
Download [Hideout Recipe Updater](https://github.com/Hazeofdream/hideout-recipes/blob/master/Hideout%20Recipe%20Updater.pyw) and install it to your root SPT Folder, Running this file pulls all json files from this repository and places it in your recipes folder.

# Creating Recipes
Download [Hideout Recipe Creator](https://github.com/Hazeofdream/hideout-recipes/blob/master/Hideout%20Recipe%20Creator.pyw) and fill out the prompts, Use "Generate Recipe" and copy the json output to a json file in the recipes folder: "SPT\user\mods\HideoutRecipeFramework\recipes"
